July 1 - June 30

Reporting Requirements

Upload the following files to NEO Financial by August 30

  • Actual Revenue
  • Actual Expenditure
  • Actual Balance Sheet

Before submitting, check that all files:

  • Are created under Quarter 4, and represent transactions from July 1 through June 30
  • Contain data for fund code series 1000, 2000, 3000, 4000, 6000 and only use 9000 when reporting Special Education regional program data.
  • For Balance Sheet files only - verify that the balance sheet is "in balance"

After file submission

  • Check the status of your file
  • If the file has errors, resolve them and upload again
  • If the file is in approved status, complete the file submission by electronic certification

Please note: Only file submissions in migrated status are considered received by Maine DOE.
